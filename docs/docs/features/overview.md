# Features Overview

Parascope provides a comprehensive suite of tools for engineering modeling.

## Visual Graph Editor

Build calculation graphs from constants, inputs, functions, and outputs. Connections show how values flow through a model, and the editor evaluates the graph as you work.

<img src={useBaseUrl('/img/node_editor.png')} alt="An aerodynamic drag calculation represented as connected nodes in Parascope" />

## Parameter Sweeps

Explore how design variables affect results with one- or two-variable parameter sweeps and interactive visualizations.

<img src={useBaseUrl('/img/sweep.png')} alt="A two-variable rocket-equation sweep visualized as a three-dimensional surface" />

## AI-Assisted Function Authoring

Generate a starting point for function code from a natural-language description. Review generated logic before using it in a calculation.

<img src={useBaseUrl('/img/function_genai.png')} alt="Parascope function editor with an AI prompt for generating a gain crossover frequency calculation" />

## Rich Function Descriptions

Document assumptions, equations, and results with Markdown and rendered mathematical notation.

<img src={useBaseUrl('/img/function_md_preview.png')} alt="A function editor preview showing a formatted engineering description and equations" />

## Mobile-Friendly Views

Review version snapshots and sheet descriptions on smaller screens.

<img src={useBaseUrl('/img/mobile_layout.png')} alt="Parascope version snapshot and descriptions view on a mobile screen" width="390" />
